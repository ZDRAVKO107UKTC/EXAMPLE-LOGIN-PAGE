# 🔐 Login Form Project – HTML & CSS (Blue Theme)

This project is a responsive login form built using **HTML5** and **CSS3** as part of a web design exercise (Упражнение 90). It includes a styled form with username and password fields, a submit button, a cancel button, and a "forgot password" link. The layout uses a blue color scheme and is easily customizable.

## 🎯 Features

- ✅ Modern login form layout using `<div>` containers
- ✅ Responsive width with centered alignment
- ✅ Styled input fields with hover/focus effects
- ✅ Submit and Cancel buttons
- ✅ Password recovery link
- ✅ Blue-themed login box (`#1702f9`)

## 🌐 How to Use

1. Clone or download the project folder.
2. Make sure the `images/` directory contains `img_avatar.png`.
3. Open `login.html` in your browser.
4. Customize styles via `style.css` as needed.

## 🎨 Customization

To change the theme colors, modify the following selectors in `style.css`:

```css
.login-container {
    background-color: #1702f9;
}

.cancelbtn {
    background-color: #c7a900;
}

a {
    color: #ffdf00;
}
